## Задание: Юнит-тесты

### Описание

Юнит-тесты для проверки программы заказа бургеров **Stellar Burgers**.

### Реализованные сценарии

Реализованы юнит-тесты для класса `Burger`.

### Структура проекта

- `praktikum/` — пакет, содержащий код программы
- `tests/` — пакет, содержащий юнит-тесты для класса `Burger`

### Запуск автотестов

**Установка зависимостей**

```bash id="qexh9k"
pip install -r requirements.txt
```

**Запуск автотестов и создание HTML-отчёта о покрытии**

```bash id="w09zgp"
pytest --cov=praktikum --cov-report=html
```
